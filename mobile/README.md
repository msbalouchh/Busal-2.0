# BUSAL Mobile

Touch-first companion application for BUSAL OS. It retains the web platform's Manrope-based dark visual language and is designed for daily operational workflows: overview, orders, kitchen, reservations, CRM, and notifications.

## Setup

```bash
pnpm install
pnpm build
npx cap add android
npx cap add ios
pnpm sync
```

Run `pnpm dev` for browser design work. Native folders are generated by Capacitor and deliberately ignored until they are created locally.

## Production integration checklist

- Replace the presentation data in `src/app.tsx` with BUSAL's authenticated API client.
- Pass the server-resolved user, business, workspace, and branch context to every request.
- Configure Universal Links/App Links and secure OAuth callback URLs.
- Add Keychain/Keystore-backed auth-token storage, biometric unlock, and push credentials.
- Keep plan purchase, trial, and subscription changes compliant with App Store and Google Play billing rules.
