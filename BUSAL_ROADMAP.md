# Development Workflow

Every milestone follows this process:

1. Planning
2. Architecture Review
3. Implementation
4. Local QA
5. Production QA
6. Approval
7. Git Commit
8. Git Push
9. Vercel Deployment
10. Live Verification

Never skip steps.

---

# Definition of Done

A milestone is complete only when:

✓ UI approved

✓ Architecture approved

✓ Build passes

✓ Typecheck passes

✓ Responsive

✓ Accessible

✓ No console errors

✓ No hydration issues

✓ Git committed

✓ Git pushed

✓ Production verified
